Welcome to the repository for Autonomous Delivery at Virginia Tech!

## Dev Container Setup

1. Install Docker
    * Windows - [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/)
        * I don't use windows. Someone please check / fix this
        * Do we need WSL?
    * Linux - [Docker Engine](https://docs.docker.com/engine/install/)
        * You can also install Docker Desktop if you want
2. Install [VS Code](https://code.visualstudio.com/Download)
3. Install Docker Dev container extension in VS Code
4. Clone the repository over ssh or https
5. In VS Code run `>Dev Containers: Open Folder in Container`
